AI Journal

A lightweight mood journaling app that analyzes your writing and gives personalized insights.

Features:
- Detects primary and secondary emotions from free-form writing
- Scores your mood (1–10) with a visual bar
- Provides 3 psychological insights about your entry
- Suggests a personalized affirmation and one actionable tip
- Tracks mood history over time and detects patterns
- Saves everything locally in a JSON file

Quick Start:
1. Clone the repo: git clone https://github.com/shivanshwahiii/ai_journal.git
2. Navigate into the folder: cd ai_journal
3. Run the script: python journal.py

Project Structure:
ai_journal/
│── journal.py        # Main script
│── data.json         # Local storage file
│── README.md         # Project documentation
